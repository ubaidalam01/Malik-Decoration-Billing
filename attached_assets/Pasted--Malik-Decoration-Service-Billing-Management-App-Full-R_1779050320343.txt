  'bowl':'باؤل',
  'plate':'پلیٹ',
  'spoon':'چمچ', 'chamcha':'چمچ',
  'fork':'کانٹا', 'kanta':'کانٹا',
  'knife':'چھری', 'chhuri':'چھری',
  'tray':'ٹرے',
  'dabba':'ڈبہ',
  'tokri':'ٹوکری',
  'jhadu':'جھاڑو',
  'broom':'جھاڑو'
};

function romanToUrdu(text) {
  if (!text) return '';
  const lower = text.toLowerCase().trim();
  if (ROMAN_TO_URDU[lower]) return ROMAN_TO_URDU[lower];
  const words = lower.split(/\s+/);
  const converted = words.map(w => ROMAN_TO_URDU[w] || w);
  const result = converted.join(' ');
  return result !== lower ? result : '';
}
```

**How it works in the Add Item modal:**
1. User types Roman Urdu in "Item Name" input
2. `oninput` fires `previewUrdu()` which calls `romanToUrdu()`
3. If conversion found: show Urdu preview hint below input (`direction:rtl`) AND auto-fill the "Saved Name (Urdu)" input
4. If no conversion: copy raw text to Urdu input
5. On save: use the Urdu input value as the final item name

```

  → state.editingBillId = bill.id
  → state.bill = deep copy of bill data
  → state.page = 'new-bill'
  → renderAll()

  → find bill by editingBillId in state.bills
  → update in-place
  → save()
  → state.editingBillId = null
  → resetBill()
  → navigate('bills')

## 22. Key Implementation Notes for Replit

1. **Single file only** — everything in `index.html`. No `package.json`, no npm, no build step.
2. **CDN scripts** must load before the `<script>` block. Use the exact CDN URLs provided above.
3. **localStorage keys** must be exactly: `mds_items`, `mds_bills`, `mds_nextId`.
4. **PDF totals box** must be `boxW = W - mg*2 = 182mm` wide and `52mm` tall to fit all 4 rows (Sub Total, Advance, Total, Remaining) — the Remaining row must be inside the box, not below it.
5. **Urdu font** — use `font-family: 'Noto Nastaliq Urdu', 'Segoe UI', sans-serif` for all item name cells.
6. **All rendering** is done via `innerHTML` injection — no virtual DOM, no React, no Vue.
7. **Bill editing** must deep-copy the bill's items array to avoid mutation: `JSON.parse(JSON.stringify(b.items))`.
8. **Gold color** (`#c17f3a`) is the primary brand accent — used for sidebar active state, buttons, rate badges, PDF header.
9. The `previewUrdu()` function must wire to both the hint `<div>` and the Urdu name `<input>` simultaneously on every keystroke.
10. Default items load only if `localStorage.getItem('mds_items')` returns `null` — existing user data must be preserved.
